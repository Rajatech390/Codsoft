Password Generator
This is a simple Python-based password generator that allows users to generate strong, random passwords with customizable lengths and complexity. The password generator includes a combination of uppercase and lowercase letters, digits, and special characters.

Features
Customizable Length: The user can specify the length of the password.
Randomized Complexity: Generates passwords containing letters (both uppercase and lowercase), numbers, and special characters to ensure a strong password.
Easy to Use: Simple Python program that prompts the user for input and generates a password.

Requirements
Python 3.x
The random and string modules are built into Python, so no external dependencies are required.
